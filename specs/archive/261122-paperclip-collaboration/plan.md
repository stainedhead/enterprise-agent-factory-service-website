# Plan: paperclip-collaboration

Status: In progress.

## Development approach

TDD per slice (domain, use case, adapter, component, e2e). SDK first and released as 1.0.1; the console follows milestone by milestone. A commit and push after each milestone and each documentation step.

## Phase breakdown

1. C1-SDK: resync, SDK additions and tests, permission mirror, `ScreenId`, header role colour, fake API with `collaborator`.
2. C1: T3 role step, T16 core with switches, connected agents, managed secrets, navigation, T1/T2, T4, T6.
3. C2: V3, S2/S3 guardrail, S10 tab with endpoint list, identity provider and templates.
4. C3: edit endpoints with mode, rotate keys, guidance and alerts.
5. C4: collaboration report, swarm template, docs, screenshots.

## Critical path

Contract pin -> codegen -> SDK -> permission mirror -> fake API -> T16 -> baselines.

## Testing strategy

Vitest for SDK, domain, use cases and components; Playwright e2e on the fake API; axe, sentinel and CSP specs; visual baselines regenerated by CI (`[regen-baselines]`).

## Rollout strategy

Release 1.0.1 (SDK tag `sdk-v1.0.1`); the console ships with the REST API and database at the same version.

## Success metrics

`bun run gate` green; coverage floors held; WG1..WG5 measures in the PRD.
