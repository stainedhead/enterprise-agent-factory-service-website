## 3. Read-before-write readers (RQ-4)

Operations needing `If-Match` with no `GET` on the same path, and the list operation that serves as their
reader (match on the last path parameter against `id`, `name` or `key`; `UpdateWorkOrderRepo` matches
`host` + `repo`):

`DeleteAgentTemplate`→`ListAdminAgentTemplates`; `DeleteServiceApiKey`→`ListServiceApiKeys`;
`UpdateModel`→`ListAdminModels`; `Update/DeleteServiceNotificationChannel`→`ListServiceNotificationChannels`;
`RemoveSecurityOperator`→`ListSecurityOperators`; `DeleteServiceTag`→`ListServiceTags`;
`DeleteStorageClass`→`ListStorageClassesAdmin`; `DeleteAgentConfigValue`→`ListAgentConfigValues`;
`DeleteAgentIdentity`→`ListAgentIdentities`; `DeleteApiKey`→`ListApiKeys`;
`DeleteNamespaceConfigValue`→`ListNamespaceConfigValues`; `Update/DeleteTeamExternalSystem`→`ListTeamExternalSystems`;
`UpdateMember`/`RemoveMember`→`ListMembers`; `DeletePoolConfigValue`→`ListPoolConfigValues`;
`DeletePoolRoleLink`→`ListPoolRoleLinks`; `Update/DeleteReportSchedule`→`ListReportSchedules`;
`Update/DeleteStage`→`ListStages`; `UpdateWorkOrderRepo`→`ListWorkOrderRepos`. The other 20 have a `GET` on
the same path.

## 4. Findings against the contract (for `-restapi`; recorded in implementation-notes.md *Contract questions*)

| # | Finding | Effect here | Interim |
|---|---|---|---|
| F-1 | `Me.servicePermissions[]` exists in the OpenAPI but not in contract §5 `Me` | `can()` for service-level permissions (no `teamId`) | `can()` reads `servicePermissions` when present, else the PRD rule (`serviceAdmin` → all; `securityOperator` → its column). Both tested |
| F-2 | `ApiKey` has no `version`, yet `DeleteApiKey` and `DeleteServiceApiKey` require `If-Match` | SDK cannot send a real version | CQ-2 to `-restapi` (add `version`); interim: the reader returns the key and, for a schema with no `version` property, the SDK sends `If-Match: "1"` (keys are immutable after create). Isolated in one generated table entry, removed when CQ-2 lands |
| F-3 | `IfMatchPut` description says "Required when the resource exists (428 otherwise)"; contract v1.2.0 §1 and CD-2 say optional on `PUT` | id-only `PUT` behaviour | SDK sends `If-Match` on `PUT` when it holds a version, and for an id-only `PUT` with a reader it reads first (absent → no `If-Match`); correct under both readings |
| F-4 | `MeTeam.role` is `team_admin | team_viewer | workload`; security operators appear only as `securityOperator: true` | Header role pill and nav | As PRD WEB-3 |
| F-5 | `info.version` 1.1.0 and `X-Afs-Contract-Version` example 1.1.0, while the contract text is v1.2.0 | Contract-version comparison (SDK-10, D47) | SDK pins the snapshot's `info.version` (WD-8) |
| F-6 | Only 2 schemas carry `enum` as a named schema; most enums are inline | Open-enum generation | The generator opens every inline `enum` (`"a" | "b" | (string & {})`) |

## 7. Industry standards and best practices applied

- OAuth 2.0 for Browser-Based Apps (IETF BCP draft): code + PKCE S256, `state` and `nonce`, no implicit
  flow, tokens in memory, refresh token rotation where the IdP offers it, `prompt=none` for silent renew.
- RFC 9110 conditional requests (`If-Match`, `412`, `428` per RFC 6585); `Idempotency-Key` header
  (IETF httpapi draft) semantics as the contract defines them.
- AWS architecture blog "Exponential backoff and jitter" (full jitter: `sleep = random(0, min(cap, base·2^n))`).
- WCAG 2.2 AA; axe-core rules at `serious` and `critical`; WAI-ARIA APG patterns for tabs, menus, dialogs,
  comboboxes and the data grid.
- OWASP ASVS 4.0 L2, sections V3 (session), V8 (data protection), V14 (configuration: CSP, headers).
