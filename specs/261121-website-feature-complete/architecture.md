## 2. SDK

### 2.1 Generation pipeline

1. `contract:check` verifies `contract/` against `contract.lock.json` (sha256).
2. `codegen` (Bun script, `tools/codegen/`) parses `openapi.yaml` with `yaml` (dev dependency), resolves
   `$ref`s, builds `OperationIR[]` (data-dictionary §2) and `SchemaIR`, and writes:
   - `src/generated/schemas.ts`: one exported type per `components/schemas` entry; inline enums opened
     (`"a" | "b" | (string & {})`); `readOnly` properties `readonly` and optional on request types (`XInput`
     = writable fields only, generated per schema used in a request body); `Money` branded string; ids and
     timestamps `string`; `oneOf` with `null` → `T | null`.
   - `src/generated/operations.ts`: a frozen table keyed by `operationId` (method, path, params, success
     statuses, content types, `csv`, `ifMatch`, `idempotencyKey`, `reader`, `secretFields`) plus
     `CONTRACT_VERSION`.
   - `src/generated/resources/<module>.ts`: one module per SDK namespace (24 top-level + 18 `admin.*`),
     each exporting a factory `teams(core)` that returns the namespace object, with nested namespaces as
     properties (`teams(core).models.list()`), each method a thin call `core.invoke("ListTeamModels", args, opts)`.
   - `src/generated/index.ts`: re-exports for `src/index.ts`.
   Every file starts `// Code generated by tools/codegen from contract/openapi.yaml; DO NOT EDIT.`
3. `codegen:check` regenerates into memory and fails if `src/generated/` differs (CI drift check).
4. The coverage test (`src/generated.coverage.test.ts`) reads `contract/openapi.yaml` and
   `contract/operations.json` independently of the generator and asserts the facade exposes exactly the
   182 `x-afs-sdk` paths (WEB-US-1.1).

### 2.2 Method signature rule (generated)

`namespace.method(...pathParams, body?, options?)`:

- Path params in path order, positional, typed `string`. For an operation with `ifMatch` the **last**
  path param also accepts a `Versioned` value (`{id, version}` or the resource itself), whose `version`
  becomes `If-Match: "<version>"` (SDK-4, D40).
- `body` for operations with a request body (typed `XInput`); query params go in `options` (typed per
  operation, e.g. `{maxResults, nextToken, state, kind}`).
- List operations (response schema `{items, nextToken}`) return `Paginated<T>`; others `Promise<T>` with
  non-enumerable `meta`; `204` → `Promise<void>` (CD-1); `202` with body → `Promise<T>`.
- CSV operations additionally offer `.asCsv()` on the returned promise-like (`ReportCall<T>`) (SDK-8).
- `GetTeamKubeconfig` returns `Promise<string>` (YAML).
- Facade: `createAfs(options)` returns `{ core, me, auth, teams, …, admin: {settings, …} }` for
  `afs.teams.list()`. It imports every module, so it is not tree-shaken; tree-shakeable use is
  `import { AfsClient, teams } from "@afs/sdk"; const t = teams(new AfsClient(opts))`.

### 2.3 Core request flow

```
invoke(opId, args, opts)
  ├─ resolve op from table; build URL (encode path params; query from opts)
  ├─ if-match: Versioned → version | id-only and op.ifMatch=required → reader (GET or list scan) → version
  │            → meta.appliedToVersion | PUT: version if held, else reader if exists (absent → none)
  ├─ idempotency: op.idempotencyKey → opts.idempotencyKey ?? crypto.randomUUID() (fixed for all attempts)
  ├─ headers: Accept, Content-Type, X-Request-Id (opts.requestId), Authorization (auth provider)
  ├─ attempt loop (retry.ts):
  │    send → 2xx: parse by content type → attach meta (requestId, etag, contractVersion, replayed)
  │         → 401: once → supplier({forceRefresh:true}) → resend; second 401 → throw
  │         → 429/503 (any method), 409 idempotency_in_progress, network error (GET/PUT/DELETE/POST+key)
  │              → delay = Retry-After or random(0, min(cap, base·2^n)); Retry-After > 30 s → throw now
  │              → abortable sleep; attempts ≤ 1 + maxRetries
  │         → other → throw AfsError (parsed or synthesized; body text ≤ 200 chars)
  └─ contract version: header newer than CONTRACT_VERSION → onContractMismatch once per client
```

Secret hygiene: bodies are never passed to the debug hook, never kept after the request, never placed in
`AfsError`. `secretKey` is returned to the caller and not referenced by the SDK afterwards.

### 3.3 Server state, polling and conflicts

- TanStack Query v5 in `presentation/query/`. Query keys: `[area, teamId?, resource, id?, params?]`.
- **No secret in the cache:** secret-bearing mutations (`CreateSecret`, `PutSecretValue`, `RotateSecret`,
  `CreateApiKey`, `CreateServiceApiKey`, identity provider client secret) run through `useSecretMutation`,
  which calls the use case directly (no `useMutation`), so variables never enter the mutation cache; the
  returned `secretKey` goes straight to the one-time dialog's ref and is not stored in any query.
- **Polling:** `usePolledQuery(key, fn, phasesOf)` computes `refetchInterval` from `PollPolicy` over the
  phases of everything the page shows (one list query, not one per row); `refetchIntervalInBackground: false`
  and a `visibilitychange` listener (stop hidden, refetch once on return); a client-wide `ThrottleGate`
  set by any `429` with `Retry-After` suppresses polling until it elapses and shows "Slowing down".
- **Conflicts:** `useVersionedForm` keeps the user's draft; on `PreconditionFailed` it shows the 412 alert
  with *Reload*, loads the current resource beside the draft, and resubmits with the new version only when
  the user saves again.
- **Errors:** every error alert renders `requestId` with a copy button; `AccessDenied` renders
  `details.requiredPermission` and triggers a `GetMe` refetch (W-2); `Unavailable`/network after retries →
  page banner "AFS is not responding" with *Retry*; `409 team_suspended` → "Team is suspended".

### 3.4 Sign-in and session (WEB-2)

```
/sign-in → ListSignInProviders (fallback: config.providersFallback)
   one provider → redirect; several → picker (default or remembered preselected); ?provider= skips picker
   → oauth4webapi: discovery(issuer) → PKCE S256 verifier + state + nonce → sessionStorage[afs.oidc.<state>]
   → IdP /authorize (client_id = consoleClientId, redirect_uri = config.redirectUri)
/auth/callback → validate state (lookup + delete), exchange code, validate ID token nonce
   → TokenStore (memory) ← access, id, refresh, expiresAt; URL cleaned (history.replaceState) → returnTo
Renew: timer at expiresAt − 60 s → refresh_token grant (IdP registrations use refresh token rotation,
       PRD §9); without a refresh token → prompt=none in a hidden iframe to the issuer (CSP adds
       frame-src <issuer origins>, WD-30); iframe failure → session-expired flow
Reload: no tokens in memory → prompt=none top-level authorize → callback → same route
401 after SDK refresh → "Your session has expired" → keep route + non-secret drafts in memory → re-auth
Sign out → TokenStore.clear, queryClient.clear, BroadcastChannel("afs-session").postMessage("signout")
   → end_session_endpoint (id_token_hint) → /signed-out
Idle: activity listeners reset a timer (config.idleTimeoutMinutes) → sign out
```

The SDK's `bearer` supplier is `TokenStore.get({forceRefresh})`: `forceRefresh` runs a refresh-token
grant (or reports expiry, which starts the session-expired flow).

### 3.5 Shell and navigation (WEB-3, WEB-5, WEB-18)

`AppShell` = `GlobalHeader` (brand, search, environment name, role pill, identity menu with *Sign out*) +
`SideNav` (groups from `navigation.ts` filtered by `visibleWhen(me, team)`; team context shows the team
switcher) + `Breadcrumbs` + routed page. Team context is the `:teamId` route segment; *All teams* for
service admins returns to `/teams`. Route guard: an unknown route, a team not in `GetMe` (for non-service
admins), or a `NotFound` from the API renders `NotFoundPage` (never confirms existence). Viewport < 1024
px renders the "Use a wider window" notice instead of the shell.

### 3.6 Design system (`presentation/components/`)

Built once in M0-U from the mockup CSS tokens (research.md §5), CSS modules only: `Button` (primary,
normal, link; `disabledReason` renders the tooltip "Requires team-admin"), `ActionsMenu`, `Table`
(text filter, property filters, pagination with `maxResults`/`nextToken`, preferences, selection, sticky
header, empty and error states), `StatusIndicator` (dot + word from `domain/status`), `Alert`

actions), `KeyValue`, `CopyButton`, `SecretInput` (uncontrolled, masked, `autocomplete="off"`, cleared

```
EditTeamForm (presentation) ── useVersionedForm ─► UpdateTeam use case (application)
   ─► TeamsPort.update(team{id,version}, patch) ─► SdkTeams adapter (infrastructure)
   ─► afs.teams.update(team, patch) ─► PATCH /v1/teams/{id}  If-Match: "7"  Idempotency? no
   ◄─ 200 Team(v8)  → cache update        ◄─ 412 → AppError.Conflict(stale) → form shows 412 alert
```

## 5. E2E harness (`apps/console/e2e/`)

- `fake-afs/server.ts`: Bun HTTP server on a random port. Serves `/v1/*` from fixtures, keyed by method,
  path pattern and the bearer token's principal; enforces `If-Match`/`Idempotency-Key` semantics and
  returns `412`/`428`/`409` when a test sets them up; adds `X-Request-Id`, `X-Afs-Contract-Version`, CORS
  headers. Every fixture body is validated against the pinned OpenAPI at startup (fails fast).
- `fake-afs/idp.ts`: a minimal OIDC provider (discovery, authorize with auto-consent per seeded user,
  token, JWKS, end-session) issuing short-lived tokens; supports `prompt=none` and refresh tokens.
- Recorders: every request is logged in memory for assertions ("no mutating request", "one list request
  per interval", "no request but list calls" for search).
- `helpers/sentinel.ts`: scans query cache (via a test-only `window.__afsDebug` hook compiled only in
  `mode=e2e`), mutation cache, all storages, cookies, URL, history state, console output, telemetry
  requests and the DOM for a sentinel string.
- `helpers/axe.ts` (`@axe-core/playwright`, tags `wcag2a, wcag2aa, wcag21aa, wcag22aa`, fail on
  serious/critical), `helpers/visual.ts` (1440 × 900, `deviceScaleFactor: 2`, animations off, fonts
  loaded, `maxDiffPixelRatio: 0.005`).
- Projects: `chromium` (all), `firefox` and `webkit` (smoke tag), `dev` (opt-in, real dev environment,
  never in the gate).

## 6. Hosting (D43)

`apps/console/deploy/` holds `response-headers-policy.json` (CSP template with `<apiUrl>`, `<issuers>`,
`<telemetryUrl>` placeholders, HSTS, `Referrer-Policy`, `nosniff`, `frame-ancestors 'none'`),
`cache-behaviors.json` (hashed assets immutable, `index.html` and `config.json` `no-cache`, SPA fallback)
and `config.schema.json`. The platform Terraform consumes them. `deploy/build-output.test.ts` asserts the
Vite output has no inline `<script>` and no `style` element injection at runtime, every asset name is
hashed, and `index.html` references only hashed assets.

## 7. Architectural decisions

The decisions are numbered WD-n and recorded with rationale in implementation-notes.md §1. The ones that
shape structure: WD-2 (snapshot and lock), WD-3 (own codegen), WD-4 (generated resource modules + facade),
WD-5 (signature rule), WD-6 (readers), WD-9 (libraries), WD-10 (fake API e2e), WD-18 (CSS modules and
CSP), WD-21 (one list query per interval), WD-31 (secret mutations bypass the query cache). Step 4 turns
them into ADR-005.. in `docs/architectural-decision-record.md`.
